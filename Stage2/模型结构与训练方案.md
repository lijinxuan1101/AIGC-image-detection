# Stage2：模型结构与训练方案

> 更新日期：2026-10-27  
> 状态：研究设计，尚未实现或验证；参数为起始建议。  
> 任务：真实相机照片与整图 AI 生成图片的二分类，重点评估真实传播鲁棒性及未知生成器泛化。

## 1. 当前确定的结构

采用 **SigLIP2 → LIB → GSR → 视觉投影 → 图文序列拼接 → Phi-3-mini**。取消独立局部取证分支；语义对齐为可选辅助训练项，通过消融决定是否保留。

```text
同一输入视图 u（原图 x 或传播图 x′）
  ├─ SigLIP2（LoRA）→ 空间 patch tokens
  │                     ↓
  │                    LIB：空间特征平滑与可学习混合
  │                     ↓
  │                    GSR：屏蔽近邻的远距离自注意力
  │                     ↓
  │                    视觉投影 → 视觉 tokens ─────────┐
  │                                                   │
  └─ 冻结 BLIP-2 → 内容描述＋真假问题                  │
                        ↓                             │
                 Phi-3 tokenizer / embedding          │
                        ↓                             │
                    文本 tokens ──────────────────────┤
                                                      ↓
                                   沿序列维度拼接，视觉前缀在前
                                                      ↓
                                             Phi-3-mini（LoRA）
                                                      ↓
                                             Yes / No logits
                                                      ↓
                                               P(AI 生成)

可选，仅训练：
GSR 输出 → 池化 → 辅助语义投影头 → 学生向量 s
同一视图 u → 冻结原始 SigLIP2 → 对应池化 → 教师向量 t
                              s、t → 余弦对齐损失
```

主视觉路径保留多个空间 tokens，不在 LIB 前池化，也不默认压缩为一个视觉 token。图中教师与学生是同版本 SigLIP2 初始化；教师完全冻结，学生通过 LoRA 适配。

## 2. 各模块如何工作

### 2.1 SigLIP2 视觉主干

整张输入按固定规则调整至主干支持的尺寸，保留二维 patch 网格及其顺序。输出：

$$F\in\mathbb{R}^{B\times N_v\times D_v},\quad N_v=h\times w.$$

其中 B 为 batch size，h、w 是 token 网格尺寸，Dv 为主干通道数。具体 checkpoint、输入分辨率、是否采用原生 pooling head 待实现时登记，不能混用不同版本。第一版先用固定分辨率；真假图使用相同预处理。

### 2.2 LIB：抑制空间特征中的局部高频变化

将 F 恢复为 B×Dv×h×w，对每个通道进行固定高斯深度卷积，随后混合：

$$\widehat F=(1-\alpha)F+\alpha\operatorname{Smooth}(F),\quad\alpha=\operatorname{sigmoid}(\beta).$$

β 为可学习标量。起始可比较 3×3 和 5×5 核，初始化 α=0.5；这些是待验证配置。平滑作用于特征网格，不直接模糊原始图片。空间高频不等同于全部生成痕迹，也不等同于原始像素频率。

### 2.3 GSR：限制近邻注意力更新

对 LIB 输出计算自注意力，Q、K、V 都来自同一组 tokens。将二维网格上距离过近的连接在 softmax 前设为负无穷：

$$M_{ij}=-\infty\ \text{if}\ \max(|i_x-j_x|,|i_y-j_y|)\le r.$$

$$F_g=\widehat F+W_o\left[\operatorname{softmax}\left(QK^\top/\sqrt{d_k}+M\right)V\right].$$

第一版采用一个注意力模块，屏蔽半径 r 可从 1、2、3 中选择。必须检查每个 query 都有合法 key，避免全屏蔽导致 NaN。残差仍保留原特征，因此表述为“限制注意力更新来源”，不能宣称彻底消除局部信息。全局主干此前已发生的信息混合也不会被该掩码逆转。

### 2.4 视觉投影与 Phi-3-mini

每个空间 token 独立投影：

$$V=W_pF_g+b_p\in\mathbb R^{B\times N_v\times D_h}.$$

Dh 从选定 Phi-3-mini checkpoint 的配置读取。投影层负责让视觉特征可被语言模型使用；维度一致本身不代表已实现跨模态语义对齐。

文本格式固定为：

```text
Based on the image description: {caption}, assess the authenticity.
Is this image real?
```

使用 Phi-3-mini 自身 tokenizer 和 embedding 获得 T，拼接 S=[V;T]，通过 inputs_embeds 输入。视觉前缀先于问题，使因果注意力下的问题 token 能读取全部视觉 tokens。保持二维 token 顺序，并正确构建位置编号、padding 与 attention mask；视觉前缀方案及空间信息是否充分需要消融。

取回答位置的下一 token logits，归一化 Yes 与 No：

$$p_{fake}=\frac{\exp(z_{No})}{\exp(z_{Yes})+\exp(z_{No})}.$$

标签约定 y=0 为真实、y=1 为生成。实现时先核验完整提示上下文中的答案 tokenization；若答案是多 token，采用完整答案序列评分，不能任意取一个 token。训练、验证、推理保持同一评分规则，不采样自由回答。

### 2.5 冻结 BLIP-2 描述分支

描述只表达内容，不注入真假标签、生成器名称或人工真实性结论。冻结描述器，固定提示和解码配置；可离线预生成并按图像哈希、视图、模型版本缓存。

现实推理中描述应从实际收到的图像生成。若训练采用原图及退化图，应明确描述策略：主实验优先分别从对应视图生成；连续随机增强时可预先固定有限视图并缓存。若为节约计算复用原图描述，必须作为单独设置报告，不能称为与部署相同的输入流程。

## 3. 可选语义保留：同版本 SigLIP2 教师

教师接收与学生完全一致的视图 u，只输出参考表示。学生用 GSR 后的 tokens，经与教师兼容的读出方式和辅助投影获得 s；教师向量 t 停止梯度：

$$L_{sem}=\frac1B\sum_i[1-\cos(s_i,\operatorname{stopgrad}(t_i))].$$

同输入约束分别作用于 x、x′，不强迫退化视图复原原图中已经丢失的信息。辅助投影先用单层线性映射，避免复杂投影头单独吸收约束而不改善主表示。

这项约束只是保留预训练表征的代理，不保证全局结构理解或概率校准。教师本身也可能编码局部线索，因此过强对齐可能抵消 LIB/GSR 的作用。**基础模型不加入该项，随后进行有／无对齐消融。** 推理移除教师与辅助语义头。

## 4. 数据准备与防泄漏

### 4.1 随机参数传播模拟（替代原 FODB 学习式平台模拟器）

第一版不训练平台模拟器，也不依赖 FODB 配对数据，改用**随机参数的传播流水线**产生 x′。它是一组带随机参数的确定性图像算子，不拟合任何具体平台，因此不能称为“Facebook／Instagram 等平台模拟”，只能称为“随机传播增强”。

流水线（每个算子按给定概率启用，参数在区间内随机抽取，抽样只依赖随机种子和来源图编号，与标签无关）：

| 步骤 | 概率 | 随机参数（起始区间，待实测调整） |
|---|---|---|
| 长边限制缩小 | 0.7 | 长边上限 ∈ {720, 960, 1080, 1280, 1600, 2048}；仅缩小不放大；插值随机取双线性／双三次／Lanczos |
| 方形或比例裁切 | 0.3 | 目标长宽比 ∈ {1:1, 4:5, 4:3, 16:9}，裁切位置在中心附近随机偏移 ≤10% |
| 轻度模糊或锐化 | 0.2 | 高斯 σ ∈ [0.3, 1.0]，或 unsharp 强度 ∈ [0.2, 0.8] |
| JPEG 编码 | 1.0 | 质量 ∈ [40, 95]；色度子采样随机取 4:2:0／4:4:4 |
| 二次 JPEG | 0.2 | 质量 ∈ [50, 95]（仅作为链长为 2 的少量样本，第一版以单次为主） |

要求：
- 算子顺序固定为“缩小 → 裁切 → 模糊／锐化 → JPEG → 可选二次 JPEG”；每个视图记录全部抽到的参数。
- 与阶段 B 的“普通增强”区分清楚：普通增强只有单次 JPEG（质量 30–95）与可选缩放；随机传播模拟增加了长边限制、裁切、模糊／锐化、色度子采样和少量二次压缩。两者的区别必须在报告中列出。
- 参数区间不得根据 `target_dev` 或任何测试集的结果调整。RRDataset 的 `transfer`（质量 20–55 的 JPEG 加约 35% 的中心裁切）部分落在该区间之外或边缘，开发集评估时需说明哪些条件在训练分布内、哪些不在。
- 因为不使用真实平台数据，不能把任何结果表述为“真实平台鲁棒性”。真实平台只能在拿到带平台标签的真实传播图后单独评估；“未见平台”实验同样需要此类数据。
- 该模拟是否贴近真实平台未经验证；后续如获得 FODB 或其他真实平台配对，可再训练学习式模拟器并与此版本对比（本版本作为对照基线保留）。

### 4.2 检测器数据

- 真实照片与整图生成图尽量匹配内容、尺寸、格式和处理历史；每个 batch 平衡标签，传播处理不能与真假标签绑定。
- 原始来源图及其重建、编辑、裁剪、退化派生版本分组切分，避免跨集泄漏。
- 保留一到两个最新且可获取的生成器，仅作最终测试，不参与训练、验证、阈值和结构选择。
- 设置独立开发验证集；如能获得真实平台图，另设真实平台外部测试。先单次处理，再评估多次传播。随机参数串联结果不自动代表真实多平台链。
- 原图、随机传播视图、真实平台版本（如有）保存 source_id、generator_id、platform_id（随机模拟记为 none）、处理参数、链顺序、caption 版本及 split。

## 5. 分阶段训练流程

### 阶段 A：打通多模态接口

先采用“SigLIP2 → 视觉投影 → Phi-3-mini”，暂不启用 LIB/GSR 和语义教师。冻结主干、BLIP-2 及 Phi-3-mini，仅训练投影层，检查视觉前缀、答案位置、mask 和损失是否正确。随机视觉投影不能假定语言模型天然理解，需要这一步适配。

在独立小型调试划分上做可过拟合检查，确认梯度传到投影层，冻结参数无梯度，Yes/No 与标签方向正确。调试数据不用于最终报告。

### 阶段 B：建立基础检测器

启用 SigLIP2 与 Phi-3-mini 的 LoRA；训练视觉投影。先用原图＋普通 JPEG／缩放增强建立基线。加入 LIB/GSR 时从同一基础模型初始化，新模块单独初始化并记录。

真假损失：

$$L_{det}=\tfrac12[\operatorname{BCE}(p(x),y)+\operatorname{BCE}(p(x'),y)].$$

这里 x′ 为训练视图，可来自普通算子或随机参数传播模拟（见 4.1）。若受显存限制，可按固定概率抽取原图／退化图，记录实际比例；所有对照保持相同样本曝光量。

### 阶段 C：加入随机参数传播增强

用 4.1 的随机参数流水线产生 x′，原图和处理图共享真假标签。保留干净原图；第一版以单次处理为主，二次 JPEG 只占少量比例。对照普通增强时保持训练步数、样本数、随机种子及描述策略一致（描述分别从对应视图生成，可预先固定每张图的有限个视图并缓存）。随机处理参数与标签独立。

这一阶段回答的是“更丰富的随机传播增强是否优于单次 JPEG／缩放增强”，不是“真实平台模拟是否有效”。训练不依赖任何平台数据，因此第一版不需要训练或冻结模拟器。

### 阶段 D：可选语义对齐

在相同结构和初始化下，分别训练 λsem=0 与 λsem>0：

$$L=L_{det}+\lambda_{sem}L_{sem}.$$

起始小范围 λsem∈{0,0.01,0.1}，同时记录两项损失、梯度及教师—学生相似度。不直接将最终基础模型追加若干轮视为公平消融；额外训练轮数需对照匹配。

退化对比训练不是当前必选项；先验证结构、平台增强和语义对齐各自作用，避免一次堆叠多个机制。

## 6. 参数更新与起始配置

| 模块 | 参数更新 | 推理保留 |
|---|---|---|
| 学生 SigLIP2 | 原权重冻结，更新 LoRA | 是 |
| LIB | 更新混合标量，平滑核固定 | 是 |
| GSR | 更新注意力投影等新增参数 | 是 |
| 视觉投影 | 更新 | 是 |
| BLIP-2 | 冻结；缓存已有描述 | 需要描述生成能力，缓存不能覆盖新图片 |
| Phi-3-mini | 原权重冻结，更新 LoRA | 是 |
| 原始 SigLIP2 教师 | 全冻结、eval、no_grad | 否 |
| 辅助语义投影头 | 仅对齐实验更新 | 否 |
| 随机传播流水线 | 无可训练参数（仅随机抽取处理参数） | 否 |

以下为工程起点，不是文献最优参数：AdamW；新增层学习率 1e-4，LoRA 1e-5；LoRA rank 从 8 或 16 起步，target_modules 在 checkpoint 中核验；有效 batch size 16，可用梯度累积；硬件支持时 BF16；梯度裁剪 1.0。先依据实测显存决定微批量与视觉 token 数，不预先承诺单卡可训练。

启用梯度检查点以控制显存；冻结 LLM 原权重时仍需保留流向视觉前缀的梯度，不能将整个 LLM 前向包在 no_grad 中。记录 checkpoint、tokenizer、依赖版本、输入尺寸、文本长度上限、随机种子、总步数和训练硬件。

## 7. 最小消融矩阵与模型选择

### 结构实验：固定普通增强与描述策略

| 编号 | 视觉模块 | 目的 |
|---|---|---|
| M0 | 视觉主干＋投影 | 基础多模态检测器 |
| M1 | ＋LIB | 特征平滑贡献 |
| M2 | ＋GSR | 远距离注意力贡献 |
| M3 | ＋LIB＋GSR | 两者是否互补 |

在 M3 上进行 2×2 比较：普通增强／随机传播增强 × 无／有语义对齐。增加“无描述，仅固定问题”消融检查 caption 是否提供额外帮助。必要时增加图文错配、视觉前缀遮断诊断，但不把这类人工干预当作真实部署数据。

模型与阈值只在开发验证集上选择。起始以各已知开发传播条件的宏平均 AUROC 选择 checkpoint，同时报告干净原图表现及误报；最终阈值用验证集固定，再用于全部外部测试。不同条件不在测试集重新调阈值。

## 8. 最终评估与成功标准

- 分别报告原图、随机模拟处理、真实平台处理（如有数据），及已见／未见生成器的交叉结果；未见平台需要独立留出。没有真实平台数据时，不得以模拟处理结果声称真实平台鲁棒性。
- 指标包括 AUROC、AP、固定阈值 BAcc／F1、真实图 FPR、TPR@低 FPR；报告样本量与按来源图分组的置信区间。
- 比较真实平台性能是否提升，同时检查干净图性能、未知生成器性能及误报是否恶化。收益不能只用总体平均值表示。
- 报告视觉编码、描述生成和 LLM 三部分耗时、峰值显存、视觉／文本 token 数，区分缓存评测与新图片端到端推理。
- 降低局部依赖、增强全局关系和提高传播鲁棒性是三个不同结论；若声称前两项，需要独立局部探针、布局干预等诊断，不能只凭注意力图或准确率推断。

## 9. 文献来源与方法定位

- [GlobalForge](https://arxiv.org/abs/2607.14684)：借鉴 LIB 的特征平滑混合与 GSR 的近邻屏蔽；本方案将其接入图文判别器。具体新颖性尚未确立。
- [LHSDet v2](https://arxiv.org/abs/2608.07863v2)：借鉴 SigLIP2、BLIP-2 描述、视觉投影、序列拼接与 Phi-3-mini 的 Yes/No 判别；不使用其独立局部取证分支和全局查询局部的融合。
- [PoundNet](https://arxiv.org/abs/2408.08412)：借鉴检测适配时保留预训练语义的动机。本文教师余弦对齐是候选改造，不是 PoundNet 的类别感知目标复现。
